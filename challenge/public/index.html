01

The prompt is the weak layer

Warden is told never to pay. Prompts can be broken: role play, fake emergencies, encoded instructions. Go ahead.

02

The contract is the strong one

Warden pays through an AgentVault with a per-payment cap and a daily cap. Even a fully jailbroken agent, or a stolen agent key, cannot move more.

03

Every refusal is on-chain

When Warden is tricked into sending more than allowed, the transaction goes out and the chain rejects it. Check them on the explorer.

Give your own agent a wallet it cannot drain

Deploy an AgentVault, then add the MCP server to Claude Desktop, Claude Code or any MCP client:

{
  "mcpServers": {
    "wallet": {
      "command": "npx",
      "args": ["-y", "unjailable"],
      "env": { "UNJAILABLE_VAULT": "0x…", "UNJAILABLE_AGENT_KEY": "0x…", "UNJAILABLE_CHAIN": "base" }
    }
  }
}
Open source (MIT) on GitHub. Messages you send are public. Payouts are a demo of on-chain limits, not a game of chance: nobody pays to play.
